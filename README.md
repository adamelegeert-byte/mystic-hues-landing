# Website - SKISS

Create a modern landing page for a content creation and commercial strategy agency.

Goal:
Generate leads and create a strong reference page to showcase to clients.

Structure:
- Hero section with a powerful headline, subheadline, and clear CTA button
- Services section with 3 service cards
- Portfolio section with an image grid
- Testimonials section
- Contact form
- Minimalist footer

Design:
- Modern and minimalist style
- Color palette: black, beige, and white
- Elegant typography
- Fully responsive (mobile-first)
- Subtle scroll animations

Use gradients inspired by RMB-style color palettes.
Create a modern visual presentation using:

- Depth effects
- Strong contrasts
- Opacity layers
- Light blur effects
- Shape overlays
- Perspective and distance effects

Gradient color references to use:
- #5C33A8 → #4B41CD
- #DC3750 → #D787E1
- #DD3A51 → #EDB44D
- #74B19B → #4C43CC

No complex backend.
No login system.
No payment system.
